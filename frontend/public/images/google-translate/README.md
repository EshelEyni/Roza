# Google Translate attribution assets

These unmodified badge files come from Google's official [Cloud Translation attribution download](https://docs.cloud.google.com/static/translate/images/google-translate-attribution.zip).
Source: [Attribution requirements](https://docs.cloud.google.com/translate/attribution), downloaded 2026-10-23.

- `color-regular.png`: normal reader themes.
- `white-regular.png`: dark reader theme.

The badge is linked to https://translate.google.com/ and displayed only alongside results provided by Google Translate. Google brand assets remain subject to Google's brand usage guidelines; they are not covered by the Wiktionary or WordNet data licenses.
