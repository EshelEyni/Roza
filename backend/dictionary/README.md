
# Local Reader dictionary

This directory contains a compiled English–Hebrew dictionary, its Hebrew source data and the required notices. These assets must be deployed alongside the backend's build directory.

- English lexical entries, sense ordering, definitions, examples and irregular inflections: [Princeton WordNet 3.0](https://wordnet.princeton.edu/download/current-version), downloaded from https://wordnetcode.princeton.edu/3.0/WordNet-3.0.tar.gz.
- Hebrew meanings and explanatory text: [Hebrew WordNet through Open Multilingual Wordnet](https://github.com/omwn/omw-data/tree/main/wns/heb), file `wn-data-heb.tab`, downloaded 2026-10-23.
- Full required notices: [WORDNET-LICENSE](WORDNET-LICENSE) and [HEBREW-LICENSE](HEBREW-LICENSE). Preserve both when redistributing the data or derived copies.

The generated JSON joins matching WordNet 3.0 synset IDs. It has 10,050 English headwords, including compounds; the current Reader lookup accepts single words with internal apostrophes or hyphens. Only senses with actual Hebrew lemmas are included. This is a limited dictionary, not complete English coverage. Explanations are copied as supplied; absent fields are left empty. No meanings or examples are generated by AI.

## Rebuild

Extract the WordNet archive, then run from the repository root:

```powershell
node scripts/build-reader-dictionary.cjs C:\path\to\WordNet-3.0
```

The script reads the extracted `dict/` files and bundled `hebrew.tab`, writes `english-hebrew.json`, and copies the Princeton notice. It does not make network requests. Both source licenses permit redistribution under their stated notice requirements. Restart the backend to use a rebuilt dataset.

Pronunciation comes from the browser's English speech synthesis voice and is separate from this dictionary.
